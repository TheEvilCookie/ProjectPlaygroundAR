# Project Playground — физическая песочница с дополненной реальностью

## 📌 О проекте

Project Playground — это мобильное приложение с использованием технологии дополненной реальности, разработанное на базе Unity и AR Mobile для устройств Android. Проект представляет собой виртуальную песочницу, в которой пользователь может размещать и взаимодействовать с трёхмерными объектами в реальном пространстве.

Основной целью проекта является изучение возможностей AR-технологий, физического моделирования и 3D-графики, а также создание интерактивной среды для экспериментов и обучения.

Приложение может использоваться как в развлекательных, так и в образовательных целях, в том числе для демонстрации физических явлений школьникам.

## ⚙️ Возможности

- Создание виртуальных объектов в дополненной реальности  
- Перемещение, вращение и масштабирование объектов  
- Удаление объектов со сцены  
- Реалистичная физика: гравитация и столкновения  
- Проведение экспериментальных физических опытов  
- Использование приложения в учебных целях для изучения основ физики  
- Тестирование взаимодействия объектов в реальном пространстве  
- Поддержка устройств на базе Android

## 🛠 Используемые технологии

- Unity + AR Mobile
- Язык программирования C#
